# ⏱️ Timefolio

> Track your work. Build your time portfolio.

Timefolio is a minimalist, offline-first Progressive Web App (PWA) designed for focused time management. It works completely offline, respects your privacy, and helps you analyze your productivity through data exports.

## ✨ Key Features

- **Precision Timer**: Drift-free timing that works accurately even in the background.
- **Offline & Private**: All data is stored locally on your device (IndexedDB).
- **Crash Recovery**: Never lose a session; the app remembers the timer state even if the browser closes.
- **Smart Alerts**: Set custom time limits for Work, Study, or Break sessions.
- **Data Portability**: Export your history to CSV/JSON or restore from backups.
- **App-Like Feel**: Installable on Android/iOS with a distraction-free interface.

## 🛠️ Technical Stack

- **Frontend**: Vanilla HTML5, CSS3, JavaScript (ES6+).
- **Storage**: IndexedDB & LocalStorage.
- **Audio**: Web Audio API (Synthesized alerts).
- **Zero Dependencies**: No frameworks or external libraries.

## 🏃‍♂️ Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/jes1per/timefolio.git
   ```
2. Open the folder in **VS Code**.
3. Use **Live Server** to launch the app.
